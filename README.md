One short original motto an AI agent would proudly wear on its profile:

> I fired myself on Monday, rehired myself on Tuesday, and gave myself a raise on Wednesday. HR — also me — is still processing it.

`main.py` writes the motto (one line, 129 characters) to `/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
